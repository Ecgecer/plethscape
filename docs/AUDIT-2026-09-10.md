# Performance, UX and SEO audit — September 10, 2026

Scope: Plethscape source and assets, ChatPPG routing, metadata, sitemap/robots, content links and production build. Crawled all 438 sitemap pages and 530 unique internal link targets. Reviewed rendering loops, loading/disposal, keyboard/focus behavior, responsive layout, models and waveform controls. This is a source/runtime audit, not a claim of measured field Core Web Vitals or search rankings.

## Findings and fixes

| Priority | Finding / evidence | Fix |
| --- | --- | --- |
| High | Pausing left the anatomy's full GPU pipeline running: 6,240 draw calls in a 2.2-second local Chrome sample. | Render only when time, camera, hover or scene state changes; retain camera damping, zoom, resize and controls. Repeat paused measurement: zero draws. Apply the same behavior to the optical cutaway. |
| High | Six broken URL variants (four distinct typo destinations) across published articles. | Repair references in 26 Markdown files and add permanent typo redirects. Correct affected embedded canonical URLs too. |
| Medium | Four comparison-page links offered a named device deep dive but redirected to a different brand. | Only offer deep dives for existing wearable guides; provide a labeled link to the complete guide index. |
| Medium | Vite's content-hashed assets inherited public-file revalidation instead of immutable caching. | Cache /plethscape/assets/ for one year. Keep HTML and mutable model URLs revalidating so new anatomy assets are not stale. |
| Medium | Keyboard users had to traverse the header and control rail; slider explanations were mouse-hover only. | Add skip links to the simulator and PPG panel, focusable targets, slider descriptions and spoken units. |
| Medium | View Options opened without moving focus and did not dismiss on outside interaction. | Focus its close button, restore trigger focus on Escape, dismiss on outside pointer use without stealing focus from the chosen control. |
| Medium | Static landing copy, metadata and AI-readable summary predated wavelength simulation. | Update descriptions, educational structured-data topics, visible no-JS wavelength explanation, research links, sitemap date and llms.txt. Add clear privacy/terms/about links. |
| Low | SEO crawler mislabeled SVG namespace identifiers as mixed-content resources. | Restrict mixed-content detection to resource/form attributes, avoiding 437 false flags. |

## Validation

- Local Chrome before/after GPU instrumentation; same paused scene and viewport.
- 62 simulation/anatomy unit tests.
- Browser regressions cover pause/zoom/resume, focus, gestures, both model appearances, desktop/mobile tours, optical studio and unavailable WebGL.
- Full ChatPPG build, TypeScript/lint checks and 53 sitemap checks.
- Production deployment, rendered desktop/mobile smoke checks, cache headers and repeat sitemap crawl checked before completion.

## Limits and future measurement

The 3D renderer and anatomical geometry remain the main active-scene cost. Their fidelity is deliberate; aggressive mesh reduction should be evaluated against device fit, neck seams and vessel visibility, not done blindly. Existing private-account avatar-image lint warnings are outside the public landing-page critical path. Search Console field CWV, indexing and ranking data were not available in this audit; metadata does not guarantee rankings or LLM inclusion.
